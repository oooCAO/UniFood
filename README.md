## Название проекта
UniFood

## Описание проекта
Веб-приложение для предварительного заказа еды
в столовых/кафе ГрГУ им. Янки Купалы
с последующим самостоятельным получением заказа.

## Функциональные требования

### Студент
1. Регистрация и авторизация
2. Просмотр заведений
3. Просмотр меню
4. Просмотр категорий
5. Просмотр информации о блюде
6. Добавление блюд в корзину
7. Изменение количества
8. Удаление блюд
9. Выбор места получения
10. Выбор времени получения
11. Оформление заказа
12. Просмотр статуса заказа
13. Просмотр истории заказов

### Сотрудник
1. Авторизация
2. Просмотр поступивших заказов
3. Просмотр состава заказа
4. Просмотр времени получения
5. Изменение статуса заказа
6. Подтверждение выдачи заказа

### Администратор
1. Управление пользователями
2. Управление заведениями
3. Управление категориями
4. Управление блюдами
5. Управление доступностью блюд
6. Управление временными слотами
7. Просмотр статистики
